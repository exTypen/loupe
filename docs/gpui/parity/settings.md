# Settings parity (ST-01..20, UP-01..04)

Both apps ran on the same fixture: mock forge on port 8808, folder `/tmp/flows-settings`, account `alice` at
`http://127.0.0.1:8808`. Swift is the prebuilt LoupeFlows.app at `fde8251`. Screenshots are in
`/tmp/flows-settings/shots/` (`swift-*` and `gpui-*`). Code: `app/src/views/settings.rs`, `settings/account.rs`,
`settings/editor.rs`.

Look: GPUI draws cards, pills and a segmented tab strip instead of a native TabView, grouped Form and
pop-up buttons (PORT.md). That applies to every row, so it isn't repeated below.

Idle CPU with Settings open (General tab, after picking Off): `ps` showed 0.0 % and the same CPU time twice, 10 s
apart. Nothing in the window polls. The AI CLI scan and the model listing run on the background executor. Leaving
the General tab drops a model listing that is still running, and closing the window drops every task. The model
lists are cached once per launch for each harness, because a CLI takes up to 20 s to list them.
